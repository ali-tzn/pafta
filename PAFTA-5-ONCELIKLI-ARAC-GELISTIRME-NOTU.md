# PAFTA — 5 Öncelikli Araç Geliştirme Paketi

## Geliştirilen sayfalar

- PDF Birleştirme
- PDF → PNG / JPG
- Mimari Ölçek Hesaplama
- TAKS–KAKS / Emsal Hesaplama
- Merdiven Hesaplama

## Eklenen içerik katmanları

- Adım adım kullanım
- Hesaplama mantığı ve formüller
- Uygulamalı örnekler
- Sık yapılan hatalar
- Sayfaya özgü sık sorulan sorular
- FAQ yapılandırılmış verisi
- İlgili araçlara açıklamalı dahili bağlantılar
- PDF → PNG için format ve DPI karşılaştırma tablosu

## Kurulum

ZIP içeriğini PAFTA proje klasörüne çıkartın ve mevcut dosyaların üzerine
yazılmasına izin verin.

```powershell
npm run build
npm run dev
```

Netlify deployment işlemi gün sonundaki toplu güncellemede yapılabilir.
